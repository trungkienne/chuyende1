# Cafe Laravel Project (chuyende1)

## Giới thiệu
Đây là project web được xây dựng bằng Laravel.

## Chức năng
- Quản lý sản phẩm
- Quản lý danh mục
- Quản lý đơn hàng
- Quản lý người dùng

## Cài đặt

### 1. Clone project
git clone https://github.com/trungkienne/chuyende1.git

### 2. Cài thư viện
composer install

### 3. Tạo file môi trường
cp .env.example .env

### 4. Tạo key
php artisan key:generate

### 5. Chạy project
php artisan serve

## Công nghệ sử dụng
- Laravel

- Blade Template
